# meDRA — demo

Animated demo of **meDRA** (Mapa del razonamiento expresado), a práctica final idea for
*Inteligencia Artificial en las Organizaciones* (UC3M, 2026/27).

A chain-of-thought trace streams in while text mining (limpieza, lematización,
frecuencias, TF-IDF por tramo, agrupación) builds a live concept map, a topic timeline
and a directed step graph.

**Live:** https://joejbaldwin.github.io/medra-demo/

The trace is simulated and the demo is a scripted mock-up; it is not the project's real pipeline.
